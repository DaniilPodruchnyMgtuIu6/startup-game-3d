# story-clip-data-loss-aftermath (project-files-destroyed closing beat)

- Tool/model: Higgsfield MCP / nano_banana_2 (keyframe) + kling3_0_turbo (image-to-video)
- Date, session: 2026-07-29
- Cost: 1 keyframe ~1.5 cr + 1 video ~7.5 cr
- Aspect/resolution: 16:9, 720p, 5 с, без звука (проигрывается muted)
- Jobs: кейфрейм 42858fe8-cfa9-49d1-8bb8-f7410a6a2aa4, видео 39df4d1b-8887-454a-a1be-4d8735a36f12
- Причина: живой отзыв игрока — старая заглушка (`playShot('dolly-out', ...)`,
  медленный отъезд камеры без слов) читалась непонятно. Заменена сгенерированным
  роликом в том же стиле, что и у intruder, с однозначным смыслом.
- Style: soft Pixar-like 3D, тот же язык офиса (стеклянные перегородки,
  тёплый пол, синяя акцентная стена), холодный рассветный синий свет,
  никого нет в кадре — «утро без проекта».
- Сюжет: медленный докрут камеры на монитор посреди пустого офиса —
  экран показывает пустой файловый браузер с перечёркнутой красным
  крестом иконкой папки (репозиторий/копия недоступны), мелкие красные
  отметки ошибок по краям экрана, пыль в холодном утреннем свете,
  брошенная кружка, стул отодвинут, бумаги на полу. Ничего не двигается,
  кроме самой камеры — намеренно безлюдно, смысл читается однозначно без
  единого слова текста.
- Post-processing: нет
- Result: public/cutscenes/data-loss-aftermath.mp4
- Использование: `StoryConsequenceController.tsx`, сцена
  `project-files-destroyed` — клип проигрывается ПОСЛЕ диалога (тот уже
  проговаривает факты), как финальная безмолвная точка. При недоступности
  файла/кодека — полный откат на прежний `dolly-out`.
