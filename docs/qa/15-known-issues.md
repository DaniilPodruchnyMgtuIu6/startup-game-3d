# Feature 15 — Known Issues

P0/P1 дефектов на момент проверки нет. Ниже — принятые P2/P3 и не выполненные в автоматическом прогоне интерактивные проверки. Ни один пункт не блокирует релиз.

## P2 — принятые

### KI-01 — Итог чистого пути выше целевой полосы баланса
- **Severity:** P2 (баланс).
- **Воспроизведение:** `tools/balance/campaignScenarios.test.ts` → BAL-01 (с Ильёй) даёт остаток 1 442 000 ₽, BAL-02 (без Ильи) — 1 649 000 ₽.
- **Ожидание §11:** 250 000–900 000 ₽ (с Ильёй) / 150 000–900 000 ₽ (без).
- **Влияние:** победа достаётся слишком «богато»; ощущение экономического давления ниже задуманного. Прохождение при этом выигрышно и не сломано.
- **Причина:** 14 задач завершаются за ~23 dev-дня → выпуск к ~спринту 3, накапливается мало дней расходов.
- **Workaround / предложение:** увеличить `TOTAL_EFFORT_DAYS` **или** `BASE_DAILY_COST`/зарплаты (один блок §29) с полным повторным прогоном BAL-01–14 и обновлением unit-тестов. Не применено намеренно — правило §12/§29 (балансировать только после первичного отчёта, без молчаливых правок).
- **Почему не блокер:** нет soft-lock, кампания проходима всеми стратегиями, все исходы достижимы.

### KI-02 — Ранний выпуск раньше окна «середина 4-го спринта»
- **Severity:** P2 (баланс). Тот же корень, что KI-01. Выпуск возможен на спринте 3, дне 4.
- **Workaround:** та же предлагаемая правка эффорта/расходов.
- **Не блокер:** ранний выпуск валиден правилами (F13); влияет только на темп.

### KI-03 — Ценность Ильи в симуляторе занижена
- **Severity:** P2 (модель тестирования, не игра).
- **Причина:** «чистая» модель симулятора сидирует `findings: []`, поэтому не отражает, что Илья закрывает замечания без отвлечения Кирилла. В самой игре этот эффект реализован (F08/F11) и покрыт интеграционными тестами.
- **Workaround:** расширить симулятор корректирующим планом для точного сравнения diverted-дней. Не блокер.
