## P2 — принятые

## Не выполнено в автоматическом прогоне (принятые пробелы верификации)

### KI-04 — Браузерная E2E-матрица не интегрирована в `verify`
- Playwright не добавлен в devDependencies; headless smoke-скрипты применялись при приёмке F11–F14, но не закоммичены как E2E-набор. Обязательные E2E (`E2E-01…08`) оформлены протоколами в `15-manual-test-matrix.md`.
- **Влияние:** сквозная браузерная регрессия автоматически не гоняется. Логика ядра покрыта unit/integration.

### KI-05 — Ручные проверки: soak, resolutions, live DeepSeek smoke, RUN-01–10 UI
- 30-минутный NPC soak, проверка UI на 1366×768/1920×1080/2560×1440, live DeepSeek smoke (≤1 запрос на NPC, без секретов в логе) и полные ручные RUN-01–10 через UI — **не исполнялись** в этом автоматическом прогоне; описаны протоколами.
- **Влияние:** визуальная/производительная полировка и «живое» качество ответов ИИ не подтверждены автоматически.

### KI-06 — Headless canvas-захват пуст в текущей среде
- **Severity:** P3 (инфраструктура верификации, не игра).
- **Симптом:** при снятии скриншота через SwiftShader canvas остаётся белым и в console видны `THREE.GLTFLoader: Couldn't load texture blob` (текстуры персонажей). Сцена при этом жива: рейкаст-клики попадают в объекты, HUD/оверлеи работают, NPC перемещаются между кадрами.
- **Влияние:** визуальная приёмка новой позиции whiteboard и стены выполнена функционально (рейкаст + панель + геометрические тесты), но кадр сцены в отчёт не снят. На реальном GPU в предыдущих итерациях сцена рендерилась корректно.
- **Workaround:** ручной визуальный прогон на реальном GPU (WB-10 в manual matrix).
