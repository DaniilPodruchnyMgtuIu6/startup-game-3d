# Lighting — «утро без проекта»

Во время разговора остаётся текущее дневное состояние (спека 17C: поражение
применяется ПОСЛЕ реплик — менять порядок эффектов запрещено). Холодное
«утро» наступает в момент регистрации поражения: state `failure` (18E)
демпфирует свет, мониторы гаснут — финальный dolly-out уже частично
захватывает переход.
