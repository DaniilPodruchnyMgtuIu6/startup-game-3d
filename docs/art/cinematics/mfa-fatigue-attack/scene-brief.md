# Scene brief — mfa-fatigue-attack

**Аспект безопасности:** MFA push fatigue, компрометация учётной записи, разница между «сменить пароль» и «отозвать активные сессии».

**Участники:** Кирилл Морозов (ведёт), Соня Соколова, Алина Белова, Илья Власов (если нанят).

**Локация:** open space, рабочее место Кирилла.

**Завязка:** ночью телефон Кирилла заваливает запросами подтверждения входа (push notifications). Он несколько раз нажимает «Отклонить», но признаётся, что мог случайно нажать не туда. Утром на аккаунте видна новая активная сессия с неизвестного устройства. Команда должна решить, что делать — и физически понять, что смена пароля сама по себе не отзывает уже активную чужую сессию.

**Тон:** усталая тревога после бессонной ночи, не паника — акцент на то, что решение нужно принять с неполной информацией («не знаю, сколько раз», «кажется, один раз мог нажать не туда»).

**Higgsfield-вставка (опционально, 4–8 сек):**
1. крупный план телефона — экран с чередой push-уведомлений "Подтвердить вход?";
2. палец нависает над кнопкой, колеблется;
3. экран монитора — список активных сессий, одна подсвечена красным как "неизвестное устройство";
4. Кирилл смотрит на экран, обеспокоенное выражение;
5. возврат в интерактивную 3D-сцену — **до** выбора.

**Ограничения:** без реальных инструкций по обходу MFA, без реальных названий устройств/ОС, персонаж соответствует approved identity, одежда/офис совпадают с игрой. Ролик не должен показывать конкретный способ атаки (никаких пошаговых инструкций) — только последствие (много уведомлений подряд ночью).
