# Scene brief — external-ai-data-disclosure

**Аспект безопасности:** чувствительные данные и governance при использовании внешних AI-инструментов, теневой AI ("shadow AI"), польза vs риск.

**Участники:** Алина Белова (ведёт), Кирилл Морозов, Соня Соколова, Илья Власов (если нанят).

**Локация:** open space, рабочее место Алины.

**Завязка:** Алина быстро исправила сложный баг со state, отправив фрагмент кода внешнему AI-помощнику через личный аккаунт (в рабочем инструменте маленький лимит). Вместе с кодом она случайно отправила часть логов, где есть внутренние адреса и session id. Команда должна выбрать общую политику: разрешить без ограничений, полностью запретить, или настроить контролируемый доступ.

**Тон:** прагматичный, без демонизации инструмента — Алина искренне довольна результатом, Кирилл тоже это признаёт; тревога появляется только вокруг вопроса "а что именно туда ушло".

**Higgsfield-вставка (опционально, 4–8 сек):**
1. крупный план экрана — чат с обобщённым "ИИ-помощником" (без реального бренда), фрагмент кода вставлен в поле ввода;
2. рядом — фрагмент лога с подсвеченными (замазанными/пикселизированными) чувствительными полями;
3. Алина смотрит на экран, довольное но чуть неуверенное выражение;
4. возврат в интерактивную 3D-сцену — **до** выбора.

**Ограничения:** без реальных названий AI-сервисов/брендов (ChatGPT, OpenAI, Claude, Anthropic, Gemini, Copilot, DeepSeek и т.п. — использовать только generic "ИИ-помощник"), без реальных внутренних адресов/токенов, персонаж соответствует approved identity. Ролик не должен утверждать, что внешняя модель точно обучилась на данных команды.
