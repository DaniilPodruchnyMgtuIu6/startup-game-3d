# 3D-офис на React Three Fiber — дизайн

Дата: 2026-07-13

## Цель

Сделать визуально впечатляющую (уровень "вау, как реалистично") 3D-сцену современного
офиса стартапа, с видом сверху-сбоку (изометрия), реализованную на React Three Fiber.
Сейчас это статичный визуальный макет (шоурил) без игровой логики, но архитектура должна
быть готова к тому, что позже поверх сцены добавится полноценная игра (персонаж,
взаимодействия, состояние).

Проект стартует с нуля в пустой директории `startup-game-3d`.

## Стек

- Vite + React 18 + TypeScript
- `@react-three/fiber` — рендер-движок поверх three.js
- `@react-three/drei` — хелперы: `Environment`, `ContactShadows`/`AccumulativeShadows`,
  `OrthographicCamera`, `CameraControls`, `useTexture`, `Instances`/`Instance`
- `@react-three/postprocessing` — bloom, SSAO/N8AO, vignette, tone mapping
- `leva` — дев-панель для тонкой настройки света/камеры (можно скрыть/выпилить позже)

## Структура проекта

Комнаты и мебель изолированы от камеры/сцены-оболочки, чтобы игровой слой можно было
добавить позже, не переписывая визуал.

```
src/
  scene/
    Office.tsx              — корневая сцена: здание + комнаты + свет + камера
    Building.tsx            — пол, наружные стены, кровля-обрезка (dollhouse cutaway)
    camera/
      IsometricCamera.tsx   — OrthographicCamera + ограниченный CameraControls
    lighting/
      Lighting.tsx          — HDRI Environment + key/fill свет + emissive-акценты
  rooms/
    OpenSpace.tsx
    MeetingRoom.tsx
    GameRoom.tsx
    FocusRoom.tsx            (маленькая комната на пару рабочих мест)
    ServerRoom.tsx
    Kitchen.tsx
    CeoOffice.tsx
  furniture/
    Desk.tsx, Chair.tsx, Monitor.tsx, Keyboard.tsx, Sofa.tsx,
    PingPongTable.tsx, PullUpBar.tsx, ServerRack.tsx,
    CoffeeMachine.tsx, Plant.tsx, Bookshelf.tsx, GlassWall.tsx, ...
  materials/
    materials.ts             — общая палитра PBR-материалов (дерево, ткань, металл, пластик)
    useOfficeTextures.ts      — хук загрузки текстур из /public/textures
public/
  textures/  — скачанные CC0 PBR-текстуры (Poly Haven)
  hdri/      — HDRI-карта окружения
```

Каждый предмет мебели — параметризуемый компонент (цвет/размер/поворот через пропсы),
чтобы им впоследствии мог управлять игровой код.

## Подход к ассетам и материалам

**Вся мебель и техника строится процедурно кодом** (боксы со скруглёнными рёбрами,
экструзии, латы — Three.js/drei-примитивы), а не берётся готовыми моделями из
асcет-паков. Одевается в реальные бесплатные CC0 PBR-текстуры и HDRI-освещение
(источник — Poly Haven) для реализма отражений/материалов.

Почему не готовые ассет-паки (например, Kenney): их стиль — мультяшный low-poly, что не
даёт нужного эффекта реализма, плюс в них нет тенисного стола/турника/серверной стойки —
их всё равно пришлось бы домоделировать, и стили конфликтовали бы. Процедурный подход даёт
полный контроль над консистентностью стиля и без проблем ложится на будущее развитие в
игру (компоненты параметризуемы и переиспользуемы).

## Здание и планировка

Прямоугольный однoэтажный корпус ~24 × 16 м. Кровля отсутствует, две ближние к камере
стены занижены/остеклены — камера смотрит внутрь как в кукольный дом (dollhouse cutaway).
Остальные стены — полной высоты (~2.8 м), с окнами.

Планировка — как в биг-тех компаниях: **опенспейс — центральное ядро**, вокруг — 6 комнат
по периметру, большинство со стеклянными перегородками (открытость, характерная для
крупных офисов):

```
┌────────────┬────────────────────────────────┬────────────┐
│ Переговорка │                                │  Кабинет   │
│  (стекло)   │                                │  CEO       │
│             │                                │  (стекло)  │
├────────────┤        ОПЕНСПЕЙС                ├────────────┤
│  Фокус-     │   (центральное ядро — ряды      │   Кухня    │
│  комната    │    столов, диванчики у окон,     │  (остров + │
│  (стекло)   │    растения, вывеска у входа)    │  кофемашина)│
├────────────┤                                ├────────────┤
│  Серверная  │                                │  Игровая   │
│  (глухие    │                                │  (пинг-понг│
│   стены)    │                                │  + турник) │
└────────────┴────────────────────────────────┴────────────┘
```

Серверная — единственная комната с полностью глухими стенами (функционально —
охлаждение/шум). Игровая и кухня — с широкими проёмами/барными стойками, читаются как
продолжение общей зоны отдыха.

## Камера

`OrthographicCamera` (истинная изометрия, без перспективных искажений), фиксированный
ракурс ~45° по азимуту, ~40–45° по углу места — классический вид сверху-сбоку. Поверх —
`CameraControls` из drei с жёстко ограниченным диапазоном (небольшой довод азимута ±25° и
зум), чтобы всегда сохранялся читаемый вид сверху-сбоку и нельзя было провернуть камеру
"под пол" или в чистый топ-даун.

## Свет и постобработка

- HDRI (Poly Haven, CC0) — мягкое окружение для реалистичных отражений на стекле,
  мониторах, металле
- Направленный "солнечный" key-light через окна с мягкими тенями (PCSS/soft shadow map)
- Fill-light для подсветки теней в комнатах без окон (серверная, фокус-комната)
- Точечные emissive-акценты: свечение мониторов, LED на серверной стойке, подвесные
  светильники на кухне
- Постобработка: SSAO/N8AO (контактные тени), Bloom (свечение экранов/LED), ACES Filmic
  tone mapping, лёгкая тёплая цветокоррекция

## Меблировка по комнатам

**Опенспейс (центр):** 3–4 кластера по 4–6 столов (бенч-система, кабель-менеджмент),
эргономичные кресла (несколько цветовых вариаций), на каждом столе — монитор(ы) с
эмиссивным экраном, ноутбук, клавиатура/мышь, кружка; зона отдыха с диванами и низким
столиком у окна; высокие растения-разделители между кластерами; акустические подвесные
потолочные панели; вывеска/лого стартапа у входа; ковровая плитка с зонированием по
кластерам.

**Переговорка (стекло):** стол на 8 мест, эргономичные кресла, ТВ-панель на стене
(эмиссивный экран), камера/спикерфон видеоконференции на столе, маркерная доска со
следами маркера, подвесные светильники над столом.

**Кабинет CEO (стекло):** стол с изогнутой столешницей, кресло-капитан, книжный шкаф с
книгами (процедурные корешки разных цветов), диван/кресла для посетителей, растение в
напольном кашпо, намёк на городской скайлайн за окном.

**Фокус-комната (2 места, стекло):** два стола у противоположных стен, шумоизоляционные
панели, настольные лампы, наушники на столе.

**Кухня (остров + кофемашина):** кухонный остров, встроенная кофемашина (эмиссивные
индикаторы), холодильник, барные стулья, навесные шкафчики, ваза с фруктами/снеками,
высокие столы для перекуса.

**Игровая (пинг-понг + турник):** теннисный стол с сеткой и ракетками, турник на
стене/раме, диван/кресло-мешок, аркадный автомат или дартс как акцент, полка с настолками.

**Серверная (глухие стены):** 3–4 серверные стойки (рейлы, юниты, вентиляторы, мигающие
LED через emissive-материал), кабель-менеджмент, прецизионный кондиционер, фальшпол,
предупреждающая табличка на двери.

**Общее:** стеклянные раздвижные двери (переговорка/кабинет/фокус-комната), потолочный
трековый свет по всему зданию, розетки/выключатели как мелкие детали, растения в разных
комнатах для единого стиля.

## Текстуры и материалы

Бесплатные CC0 PBR-текстуры и HDRI с Poly Haven (лицензия не требует атрибуции, источники
будут указаны в комментарии в коде) — паркет/дерево, ковровая плитка, полированный бетон,
ткань для кресел/диванов, металл для стоек и рам. Скачиваются на этапе реализации в
`public/textures` и `public/hdri`. Там, где реальная текстура не нужна (пластик, крашеный
металл, стекло, эмиссивные экраны) — процедурные `MeshStandardMaterial`/
`MeshPhysicalMaterial` с подобранными цветом/roughness/metalness/transmission.

## Проверка качества и её ограничения

У исполнителя (Claude Code) нет инструмента для визуального просмотра рендера в браузере
(нет скриншот-тула). Проверка ограничивается:

- сборкой/`tsc` для отлова ошибок на уровне кода;
- запуском dev-сервера и проверкой, что сцена монтируется и рендерится без runtime-ошибок;
- smoke-тестом (сцена монтируется без ошибок).

Финальную визуальную оценку (композиция, пропорции, свет, "вау-эффект") даёт пользователь,
запустив `npm run dev` локально. Дальнейшие правки вносятся по обратной связи
пользователя (в т.ч. по присланным скриншотам).
